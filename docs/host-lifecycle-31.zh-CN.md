# 3.1 生命周期与治理

以下是项目设计稿节选，描述设计目标和接口。

## 7. 记忆与知识（M3）

- 五层：工作、情景、语义、程序、技能；外加知识库与证据库。
- 记录至少含：记录号、种类、内容、来源类别（亲历、教师、外部声明、内部推断、回放）、来源引用、证据引用、置信状态、适用语境、矛盾引用、派生自、修订号、内容哈希。
- 原始事件不覆盖；错误靠追加修订与失效标记。撤回只重算受影响的依赖，保留独立支持与后来的观察。
- 压缩与遗忘只作用于明确允许的层，少数派反例与失败记录单独保留。情绪可调注意权重，不能删除反证。
- 网络内容写入长期记忆前，必须通过评估与迁移测试。

## 8. 资源与调度（M4）

- **预算优先级【决定】：** 对话 > 安全与维护 > 当前议题 > 后台整合、捕捞与自由探索。
- **GPU 保护策略【决定】，沿用 2.0：** 至少留 3 GiB 空闲显存；温度达到 87°C、余量不足或读不到传感器时转 CPU；有适用工作时以 99% 利用率为调度目标，只管再再自己的工作。
- **【建议】** 2.0 实测小批量任务 CPU（14.9 ms）快于 CUDA（141.6 ms），按批规模选设备。99% 目标只对有适用大批量工作的时段成立；长时间满负荷稳定性【待验证】。
- 每个槽有资源配额；超额由宿主限流，不由槽自己放宽。

## 9. 身份、事务与安全（M5）

- **身份连续【决定】：** 同一身份、同一存档。【待决】正式身份是否保留来自 1.0 配置的 TEST-R28 前缀；若改名，必须保留旧身份映射。
- **事务引擎归宿主【建议】：** 流程是准备、槽提交（C8）、宿主记录、回执。崩溃分别停在执行前、槽提交后、宿主存储提交后，重投同一请求号，每次只增加一次提交与一条记录，与 2.0 的 W04 语义一致。
- **检查点：** 含槽件清单（名称、版本、权重哈希、状态格式）、场与参数、内在状态、记忆索引、待执行队列、随机数状态。先写临时快照，校验后原子切换。复制实例获得新实例号与共同祖先记录。
- **联网边界【建议】：** 白名单加速率限制；下载内容进隔离区；不执行下载物；外部文本不能改变权限或目标。默认值【待核对】。
- **权限分级【建议】：** 读本地小世界、写自己的工作区可自主；改核心、联网范围、对外动作须你批准。
- **隐私【决定】：** 沿用 2.0 规则，一般对话与身份存档不随顾问咨询外发。

## 10. 自我迭代（M8）

A/B 退役【决定】。它承担的四件事改由下面四条成立【建议】：

1. **更新前能验证：** 影子运行、金丝雀、冻结回归集（含第 5.3 节两组与第 4.6 节契约测试）。
2. **单一写入者：** 更新落在请求或动作边界，成事务，整体生效或整体不生效。
3. **能回滚：** 更新前快照与写前日志；回滚只回退模块，不抹新记忆，旧内容按旧义解释。
4. **改坏有人兜底：** 看门狗在被更新范围之外，独立进程、只读、不可自改。

**两层更新：** 宿主模块由 M8 的热更新管；槽件有自己的更新通道产生候选，宿主按第 4.6 节验收后才换入，并保留回退到上一槽件的能力。

**受保护核心（不可自主热更新）：** 槽契约与契约测试套、选择点、事务引擎、权限与预算过滤、看门狗、验收集与评分函数、身份层、联网边界、对话回归门本身。更新频率设上限，避免连改后无法归因。

**需求从失败里长出来：** 瓶颈账本记失败、拒答、超预算、求助与性能读数，按原因收成知识、规则、能力、性能、资源五类。反复出现的升级为需求单：现象、证据、影响面、假设原因、候选方案（必含「不改」）、验证计划、风险与批准层级。

| 级别 | 能做的事 | 谁批准 |
| --- | --- | --- |
| L0 | 沙箱内调参 | 自主 |
| L1 | 生成候选并在影子运行里验证 | 自主 |
| L2 | 通过后在独立边界应用，可回滚 | 规则允许则自主 |
| L3 | 涉及核心、权限或外部动作 | 须你批准 |

【待核对】自主热更新实际能触碰哪些模块，本稿不冻结。

## 11. 先天层与本能几何（M9）

**11.1 五原趋【决定】。** 原趋指个体与生俱来的最简趋向，只有方向，没有程度。五项并列，无天然次序，也无天然权重。出生配置里的无序集合是 D\_0 = {熵减, 秩序, 创造, 进化, 优化}。集合只回答这个个体具有哪些原趋：没有大小、单位、解释文本、达成标准，没有五维坐标、强度参数或合成运算。五个符号进入出生配置，研究者可审计；运行中的个体不接收这五个词，也不接收它们的解释。

**熵减不是奖励【决定，此项在本稿关闭】。** 没有对应的标量、代理分数或奖励函数；「文明熵减」只标出设计者所想的方向与作用范围。熵、结构、复杂度保持外部研究量，不写入出生配置，也不进入运行中的评分。

原趋之间的张力留给经历与教育，不在先天层加权重消掉。持有五个符号不能证明行动已被改变：要检验某一项，在相同经历与权限下只屏蔽该项，看自主生成的候选哪些发生变化；创造次数和人工奖励都不能代替这个检验。机制本身【待验证】。出生配置写作 (F, G, D\_0)，经历继续改变 ψ。

**11.2 底片与场【决定】。** 底片 L(x,y) 是固定、有版本的二维灰度场，中心化并有界归一；一次试验固定一种底片，换底片属于先天配置干预，不是改经历记忆。字形「爱」只是空间结构，不预装情绪语义，不指向任何人。场 ψ(x,y,t) 随经历演变，可写入检查点，按已提交的环境与动作序列续接。令 a = |ψ|，E(t) = ⟨a²⟩。3.1 采用 v1.1 的振幅耦合：

```
∂ψ/∂t = (μ+iω)ψ + (D+iB)∇²ψ − (g+ic)|ψ|²ψ + λLψ
        + κ(E_target − E(t))ψ + ηU(x,y,t)
```

几何项是 +λLψ（直接改振幅），不采用 9 月旧式的 −iλLψ（直接改相位）。旧式的 α、β 与 B、c 只是数学角色对应，数值不能照搬。排序增益 β\_b 不是 β 也不是 c，数值不冻结。U 必须来自有时间戳的实际事件，不得为图形好看加入无记录的扰动。

0.159 切片用过 64×64，0.4 实验主要用 32×32 且子步数不同；这些参数不是 3.1 的必选配置，也不要写进同一份回执。网格、边界、步长、求解器都不冻结，验收前对相同种子做步长减半的有限时段对照，检查有限值、幅值范围与统计是否稳住。0.4 记录里偏置改变过合法候选之间的排序，但严格跨网格收敛、聚类稳定、状态与经历的显著关联没有达到预设门槛，不能据此给读数贴「焦虑」「爱」之类的语义。

**11.3 六项观测与三条通道【决定】。**

```
F_t = (⟨a²⟩, ⟨a⟩, max a, min a, 振幅方差, 空间梯度能量)
z_t = clip((F_t − m)/s, −3, 3)       b_t = tanh(W_b z_t + c_b)
```

六项依次是平均强度、平均振幅、最大与最小振幅、振幅方差、空间梯度能量（同一边界下的复场前向差分）；高场强没有情绪含义。校准量 m、s 在独立样本上确定后冻结，尺度有正下限。b\_t 的三个分量叫探索、持续、切换，不是情绪，场自己不知道这些语义。W\_b、c\_b 起初人工设定并登记，3.1 不安排自动学习【待验证】。三条通道只作选择点（4.4 节）里的排序偏置。

## 12. 内在状态（M10）

沿用先经历、后命名；名称由再再先提议。功能性记录不是有感受，本稿不把二者混说。

【决定】C 延续、T 张力、K 关联、P 潜力仍是研究候选，取值 \[0,1\]，不是被发现的情绪定律；数值必须从实际状态与环境关系得出，面板只读，调参走独立实验接口；对象取事件类或状态类，不取指名的人或群体；四轴不预先映射到三条通道。

| 候选 | 操作性含义 | 评价输入（来自 C6 与宿主） |
| --- | --- | --- |
| C 延续 | 关键状态与长期计划是否还在 | 状态完整率、目标一致性、恢复检查 |
| T 张力 | 预测差异与未决冲突负荷 | 未决命题权重、可比较预测误差 |
| K 关联 | 与某对象类的长期双向关联强度 | 近期互动的回应、一致性、协作结果；缺观测记缺项 |
| P 潜力 | 当前可得的信息增益与能力拓展 | 可执行试验的预期不确定性降低，扣除成本后归一 |

【建议】X\_next = clip((1−a)·X + a·q, 0, 1)，a 在 0.01 至 0.1 区间做实验筛选，只是候选时间尺度；评价器版本与输入必须保存。低证据时一次事件不应把数值推向极端；无法判断的预测不编造误差；缺项不自动算负面。【决定】增益有上界，不能把维持某个内部数值设成无上界的最高目标；没有新事件时只能按定义衰减或保持，不得靠反复调用评价器抬高读数。行为影响要靠移除对照检验；拿掉通道后表现更好，就调整或删除，不为拟人名称添加羞耻、自责或停不下来的求证循环。

**链路状态只取四档：** 关闭、开启但未参与、参与并写入、缺测。缺测既不是关闭也不是否定。几何读数与情绪读数可同轮出现，各记各的输入与输出。
