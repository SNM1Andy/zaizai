# 3.1 宿主和插槽契约

以下是项目设计稿节选，描述设计目标和接口。

## 3. 构成

```
通道层      对话 | 课本 | 捕捞 | 世界与文件 | 顾问 | 用户教导
              ↓ 观察帧（来源、时点、说话人、通道）
宿主        感知 · 记忆与知识 · 资源与调度 · 身份与事务 · 选择点 · 先天层 · 内在状态
              ↕ 端口契约（第 4 节）
槽 L 语言    空缺：旧槽件适配器（CL 0.157）或新语言层
槽 C 认知    空缺：旧槽件适配器（PCGM 0.159）或新认知中枢
旁路        看门狗（独立进程，只读，不可被自改）
```

| 编号 | 模块 | 3.1 职责 |
| --- | --- | --- |
| 槽 L | 语言（原 M1） | 空缺，见第 4 节 |
| 槽 C | 认知中枢 | 空缺，见第 4 节 |
| M2 | 感知 | 统一观察入口：对话、课本、捕捞、文件与世界、顾问回答，全部带来源 |
| M3 | 记忆与知识 | 五类记忆、知识库、证据库、词典库版本 |
| M4 | 资源与调度 | 时钟、预算、抢占、CPU/GPU 调度、等待 |
| M5 | 身份、事务与安全 | 身份、请求号事务与回执、检查点、权限、联网边界 |
| M6 | 对话与监测 | 窗口、会话、历史、监测、主动发言队列 |

## 4. 槽契约

### 4.1 通则【槽】

1. **槽件清单。** 每个槽件登记名称、版本、接口版本、能力声明、值域声明、状态序列化格式、自检结果。宿主只认清单，不认版本号字符串。
2. **边界。** 槽只经端口读写宿主，不直接碰宿主存储；宿主不读槽内部。
3. **故障隔离。** 槽超时、崩溃、返回非法，都变成可见的「槽不可用」状态。宿主继续保存，窗口与历史照常可用，必要时回退到上一槽件。
4. **来源。** 槽的所有输出带来源引用与输入版本标识。

### 4.2 语言槽 L 的端口【槽】

| 端口 | 宿主给 | 槽返回 | 宿主验收 |
| --- | --- | --- | --- |
| L1 解析 | 一条表达与上下文 | 结构化结果，或拒绝并说明原因 | 非法输入被拒；同输入同结果 |
| L2 核验 | 查询、规则与观察快照、版本锁 | 支持状态、证明引用、来源与输入版本标识 | 状态值域由槽声明；必须有一个值表示「缺证」，且与「反证」可区分；证明可复验 |
| L3 词典 | 词或短语、语境 | 义项列表与歧义；新义项提案 | 提案先进候选，不直接改词典；新词不强塞旧义 |
| L4 表达 | 认知结论、限度、来源 | 人类可读表达 | 无固定兜底话术；不添加未发生的经历、未记录的承诺、未测量的情绪 |
| L5 复验 | 旧回执与输入版本 | 同一证明 | 版本锁下重放一致 |
| L6 自检 | 无 | 能力声明与自检结果 | 声明与实测不符则不接入 |

### 4.3 认知槽 C 的端口【槽】

| 端口 | 宿主给 | 槽返回 | 宿主验收 |
| --- | --- | --- | --- |
| C1 观察 | 观察帧流 | 确认接收 | 无漏记，无重复 |
| C2 记忆 | 读：按相关性、来源、时间；写：经宿主校验 | 检索结果；写入请求 | 原始事件不覆盖；不能删除反证；教师重复不算多份证据；派生记录不能证明其来源 |
| C3 候选 | 权限与预算快照 | 候选集合 A\_t：每项含认知基础分、合法性依据引用（来自 L2）、预期成本 | 宿主按权限与预算过滤，再进选择点 |
| C4 问询 | 路由与打扰预算 | 问询包：想解决什么、已试过什么、最佳假设与置信度、卡在哪、什么答案会改变判断、期望答案形式 | 宿主路由给你、顾问或自查，并排队 |
| C5 预算 | 每步预算、对话抢占信号 | 预算内返回；预算尽时收束：承诺带标注的假设、缩小问题，或搁置并写唤醒条件 | 超预算被强制收束；抢占时让出 |
| C6 评价输入 | 无 | 状态完整率、未决命题权重、可比较预测误差、预期信息增益，缺项注明 | 缺项记缺测，不编造 |
| C7 审计 | 轮 ID | 本轮审计条目 | 同轮读回一致 |
| C8 提交钩子 | 请求号、阶段 | 幂等的准备与提交 | 重投同一请求号只提交一次 |
| C9 状态 | 保存与恢复指令 | 可序列化状态 | 关闭重开后目标与未决问题仍在 |

没有新必要时，槽 C 应当进入等待，由宿主的时钟或事件唤醒，不做空转。

### 4.4 选择点【建议】

宿主侧有唯一一个把本能偏置与认知分合起来的选择点：

```
a* = argmax_{a ∈ A_t′} [ S_认知(a) + β_b · b(a, b_t) ]
```

A\_t′ 是槽 C 提交的 A\_t 经宿主权限与预算过滤后的集合。偏置只改变 A\_t′ 内部的排序，不能让核验为缺证或反证的候选变合法，不能放大权限，也不能制造事实。每次记录认知分、偏置贡献与最终选择。候选集合因证据、权限或预算变化时，排序变化不得归因于几何。β\_b 的数值本稿不冻结。

### 4.5 旧槽件适配器【建议】

本机现有 CL 0.157、PCGM 0.159 经适配器接入上面的端口，用途有二：在新槽件就绪前让宿主跑通 2.0 的全部对话回归；作为换槽演练的对照基线。适配器不得让宿主依赖旧版特有行为。另一份材料记录的 0.163（云端回归 98 项）只作参考，不是依赖。退役条件：新槽件通过槽验收与对话回归门。

### 4.6 槽验收【建议】

- **契约测试：** 每个端口一组合成样例，槽独立可跑。
- **故障注入：** 超时、崩溃、非法返回，看宿主表现。
- **换槽演练：** 同一存档，旧槽件 → 新槽件 → 旧槽件，身份、记忆、对话不断，旧内容按旧义解释。
- **容差：** 重放对齐的数值容差【待核对】，验收前写成具体数字，不临时指定。

## 5. 对话：不降级

**5.1 必须保留（2.0 已实测）：** 原生对话窗、监测窗、历史查找、打开核验文件、会话选择、证据窗（W16）；请求号事务与回执（W04）；词义展开与选定、歧义澄清（W07、W09）；不懂就问，含问题号与版本、错题与陈旧版本被拒、相反回答并存、撤回后重新开放（W10）；多轮追问、会话隔离、跨会话长期记忆、旧记忆回忆（W11）；比较方案、采纳最优方案、状态与「为什么」（W13）；词条自学与顾问咨询（W12）；旧会话与 85 条备份对话的迁移读取（W03）。「打开核验文件」的文件格式由语言槽声明。

**5.2 规则【决定】：**

1. **抢占与保底。** 对话线程有独立预算，可抢占任何后台步；后台学习、捕捞、整合不得饿死对话。
2. **先想清楚再回复。** 界面上的「已收到、正在推理」是状态显示，不是回复，也不是兜底话术。
3. **主动发言。** 受打扰预算与勿扰状态约束，窗口关闭时进队列；默认数字【待核对】。
4. **说真话。** 谈到「我在学什么、卡在哪」，只取自审计记录；用到情绪词时，要能追溯到内部状态读数。
5. **教导是一等信号。** 你的纠正与价值判断，带说话人与时点进入观察。
6. **对话时思考不停。** 后台继续，引用必须对得上审计记录。

**5.3 对话回归门拆成两组【决定】：**

| 组 | 内容 | 用什么验 |
| --- | --- | --- |
| 宿主独立组 | W16 窗口、W03 迁移与读取、W04 事务与回执三阶段崩溃重投、历史与会话、监测窗显示同一事务 | 槽用测试替身即可 |
| 依赖槽组 | W07 词义、W09 争议核验、W10 不懂就问、W11 多轮与记忆、W12 顾问咨询、W13 取舍 | 旧槽件适配器；换槽后重跑 |

两组全部通过、对话时延与出错率不劣于 2.0 基线，才允许合入。

**5.4 槽不可用时的底线：** 窗口、历史、会话、监测、回执、旧记忆读取仍可用。回复需要槽 L 与槽 C，槽不可用时界面显示槽状态，不编造回复。
