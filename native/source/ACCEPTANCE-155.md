# CL exact symbolic comparisons in portable, audited rules

Add pure rule conditions sym_eq(x,y) and sym_ne(x,y), for already-bound sym operands. They compare exact canonical typed symbol identity, not rendered text, order, collation, normalization or natural-language meaning. Inequality is a deterministic filter and not inference by absence; an unknown input produces no match. Reject integers/quantities, non-body context, explicit negative form, unbound inputs and alternate-format encoding. Establish explicit new CLIR capability only when these operators occur, with legacy image bytes and behavior unchanged except for the two newly reserved predicate names. An authored type profile must opt in (auditable CL rules), and output exact native IR; existing pinned profiles remain byte-stable and reject unsupported operations.

Demonstrate distinct bare and quoted names, canonically distinct UTF-8 strings, Unicode text and escaped punctuation, exact proof witnesses, recursive use when positively grounded, module lock/package detached CL and pure C proof parity, invalid profile/types and malformed image rejection, and native PCGM consumes the exact accepted compiled image without gaining any changed decision authority. Linux CPU only. No Unicode normalization, natural-language interpretation, external dispatch or production deployment.
