# CL/PCGM 0.149: canonical rank-and-scatter projection operator

Implement a bounded stable integer projection operator shared by native CL and native PCGM. It is an actual CPU computation, not CUDA emulation. Grouped relations retain the original ticket order inside identical keys. The host checks any accelerator proposal independently; callback failure remains CPU-safe. Retain byte-identical proofs, logical budget and evidence semantics across the existing map strategy, single-thread rank/scatter and two-worker rank/scatter.

Acceptance covers valid legacy 32-bit keys, dimensions 1 through 4, highly skewed and unique workloads, partially sorted keys, edge capacities, actual forced serial/parallel runs and repeated concurrency. Native executable proof comparisons and real PCGM recovered state are required, not just sorted arrays. Benchmark comparison in this cloud should use elapsed process timings across a varied corpus and report limits, without a whole-application or hardware claim. This is a CPU baseline and accelerator reference contract; do not assert GPU availability, Windows compatibility or change the official PCGM instance.

CPU dispatch: monotone/bounded integer rows use an exact linear easy path or one-worker stable counting passes where appropriate. Two-worker reference remains opt-in for parity because this cloud's small bounded batches did not justify spawning a helper. Benchmark columns 0, 1 and 2 are comparison baseline, adaptive single-thread and parallel-permitted; comparator-only time excludes rank validation, and these are kernel timings, not end-to-end throughput. Test uses 43 interleaved repetitions per case, result verified against canonical total order.
