# CL / PCGM 完整源码 · 2026-11-25 四方收尾基线

这是同一套可编译源码，并非 GitHub 公版、正式 1.0、Windows 已部署版或二进制快照。
`cl-src/` 是 CL 编译器与运行库，`pcgm-src/` 是 PCGM 推理、状态、证据及问询运行时。还包括头文件、C SDK、Makefile、算子投影接口（本快照不含独立 CUDA 后端；Windows 和真实 CUDA 无本版验证证据）、规则夹具和原生测试。数据、身份存档、外部模型凭据和 20 万候选词典包不在源码内。

Linux 需要支持 C++20 的编译器、GNU make、Python 3、sha256sum 和可用的静态链接环境。干净解包后运行 `bash handoff-checks/verify.sh`。它验证本快照清单、构建 CL 与两套 PCGM，并实跑本次定向用例。原先 0.163 的清单另存为 `BASE-0.163-SHA256SUMS`，仅做来源说明，不能拿来对覆盖后的源码验签。全历史套件及所有平台不被此命令覆盖。

有界加法示例（原句直入，计算结果未预填）：
```sh
printf '小洛，一加一等于几/\n二加三等于多少？\n' | ./pcgm-alpha --ask-basic-arithmetic
```

这个独立入口只懂约定的非负整数加法子语法；旧 `:chat` 还是结构化入口，不是开放中文。回参中的证明来自 CL/PCGM 原生求解，不是对句子绑定的答案模板。具体目标、职责和集成接口见压缩包上层蓝图。
