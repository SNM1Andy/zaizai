# 500 条 CL 技术义项

39 条基础构造、44 条组合用法和 417 条领域义项源自 DeepSeek 的历史 CL-Core-Lexicon-500 包。其原目标为 CL 0.157。basic.jsonl 与 expanded.jsonl 保存术语、别名、原始状态、来源和示例预期。fixtures 下的 CL 源文件按原始字节的 SHA-256 去重，可由每条义项的 examples 定位。

Windows 适配数据来自后续逐项复验。本批共 1,003 项示例预期，有 94 项经明确修订或调整项目入口后复验成功；原记录和适配说明分列。中文释义仍保留原始审核状态。这 500 个技术义项与 20 万候选词库中的 500 条版本修订分属两组数据。
